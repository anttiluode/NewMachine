# NewMachine v0 Two-Gate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and falsify the smallest persistent-state machine in which state-side inhibition and output-threshold inhibition can become computationally distinct.

**Architecture:** One scalar recurrent state exposes two control inputs: basket-like inhibition subtracts from the state update, while chandelier-like inhibition shifts only the event threshold. Frozen experiments add persistence and slope sensitivity separately before a matched-budget held-out task combines them.

**Tech Stack:** Python 3.11+, NumPy, pytest, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-15-two-gates-design.md`

## Global Constraints

- Tests before production code.
- Deterministic experiments with explicit seeds.
- Scientific gate outcomes are recorded, never made CI pass/fail conditions.
- No learned controller, backpropagation, Oja, oscillations, network graph, or morphology in v0.
