The point of v4 is not to reward silence. A policy only earns a place on this plot if the downstream receiver stays accurate. The Python receipt is the scientific authority; this browser lab mirrors the same equations for inspection.

1 · resident state

The sender does not reconstruct itself from scratch each frame. Its state persists and evolves.

2 · repair

A large local residual can stop a corrupted observation from poisoning future sender state.

3 · publication

Separately, a correct local state can be kept private when it is irrelevant to this receiver.

4 · prediction

When no event arrives, the receiver does not freeze; it advances its own simple predictive state.
